# pic/ 图片清单

文件名**必须与下表完全一致**（大小写敏感 —— GitHub 跑在 Linux 上，`Banner.png` 和 `banner.png` 是两个不同文件，写错就显示裂图）。

放进 `pic/` 后，主 `README.md` 里的引用**自动生效**，不需要改任何路径。

---

## 需要你做的（6 张，全部放进 pic/）

| # | 文件名 | 建议尺寸 | 内容建议 | README 里的引用位置 |
| :-- | :--- | :--- | :--- | :--- |
| 1 | `banner.png` | 1600 × 400 | 主视觉横幅。柯南剪影 + 标题（建议用英文，如 `CASE FILE: <你的ID>`）。**左右各留 ~200px 安全区**，手机端会裁掉两边 | 页面最顶部 | 
| 2 | `divider.png` | 1200 × 24 | 细横线分隔条：一条细线 + 中间一个小图标（放大镜／变声器蝴蝶结／眼镜反光）。**全页重复用 5 次**，越简洁越好看 | 各板块之间的分割线 |
| 3 | `intro.png` | 800 × 800（正方形） | 名场面：经典台词「真実はいつもひとつ／真相只有一个」。**必须是 1:1 方图**，README 里按 `width="240"` 缩放 | 「CASE FILE」板块左栏 |
| 4 | `stack-header.png` | 1200 × 200 | 技术栈板块标题图。可画：阿笠博士实验室／发光眼镜／放大镜下的代码 | 「推理装备」板块标题 |
| 5 | `agent-flow.png` | 1400 × 700 | Agent 架构示意图：把 Planner → Tool Use → Memory → RAG → Multi-Agent 画成流程图。风格随意，**箭头和方块能看清就行** | 「事件簿」板块 |
| 6 | `footer.png` | 1600 × 300 | 结尾横幅：柯南背影 + `TRUTH IS ALWAYS ONE`，与 `banner.png` 风格呼应 | 页面最底部 |

> 用 PNG。想更清晰可以换 SVG（体积小、缩放不糊），但文件名要同步改成 `.svg` 并更新 README 里的后缀。

## 不用放进 pic/ 的（在 GitHub 网站上直接设置）

| 图片 | 尺寸 | 设置入口 |
| :--- | :--- | :--- |
| 头像 Avatar | 500 × 500 正方形 | GitHub → Settings → Public profile → Profile picture |
| 社交预览图 Social preview | 1280 × 640 | Profile 仓库 → Settings → Social preview → Upload an image |

> ⚠️ 这两个**不能**用 `pic/` 里的文件代替，GitHub 只认它自己的上传入口。
